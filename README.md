# Alefantverse Frontend Demo Suite

A polished, frontend-only React + Vite presentation suite for Alefantverse.

## Included

- **Suite Home** — presentation landing page and architecture mapping
- **Eduvera** — fictional institutional/school website concept
- **Nexora Admin** — fictional React admin dashboard concept
- **Eduvera Connect** — fictional parent/student portal concept
- **Shopora** — fictional e-commerce frontend concept with working search, categories and cart
- **Nexora Insights** — fictional SaaS analytics dashboard concept
- **NovaFit** — linked as an actual completed Alefantverse project

> Eduvera, Nexora Admin, Eduvera Connect, Shopora and Nexora Insights are fictional frontend demonstrations. They are not presented as completed client deployments.

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Notes

No backend is required for this presentation version. State, search, navigation, dashboard tabs, cart interactions and demo actions are handled in the browser.

The proposed production system would connect the frontend to a Node/Express API, PostgreSQL or equivalent relational database, authentication, HTTPS, environment variables, Git/GitHub and production hosting.
